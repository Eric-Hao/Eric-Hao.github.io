# OpenAI Sans and OpenAI Sans SC

Webfont assets used for this site. These fonts are not offered under a general
public-reuse license. Original embedded copyright and license notices are
preserved; obtain appropriate permission before reusing them in another project.

Official distribution: https://cdn.openai.com/common/fonts/openai-sans/v4/
Simplified Chinese distribution: the same path followed by zh-hans-v2/.
English internal version: 1.114. Simplified Chinese internal version: 1.110.

manifest.json records source URLs, byte counts, and SHA-256 hashes.
openai-fonts.css preserves Unicode ranges and weight/style declarations.
English assets contain license metadata referring to https://abcdinamo.com/licenses .
